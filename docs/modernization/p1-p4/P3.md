## 实际测试

每个专用 ARM64 AVD 安装 debug APK 与 test APK，执行：

```sh
adb -s emulator-PORT shell am instrument -w -r moe.tarsin.ehviewer.debug.test/androidx.test.runner.AndroidJUnitRunner
```

API26（5560）、29（5564）、33（5566）、35（5568）、37（5562）均为 `OK (8 tests)`，共40次执行。API37设备实际 `getconf PAGE_SIZE=16384`，SDK37；镜像为 Android17 Canary 20261007，元数据 API37.2/CANARY，不能描述成稳定正式版认证。其余镜像4KB。

测试真实调用 APK 中 `libehviewer.so`：SHA-1空/多块/偏移及fd保留；stored/deflated ZIP、TAR、7z、AES256 ZIP和ZipCrypto；错误/正确ASCII密码；page1/2/10自然排序与关闭排序；随机重复页、DirectByteBuffer释放、extractToFd；坏ZIP；安全GIF mmap/rewrite/munmap。还有MainActivity启动/旋转请求、WebView UA/合成Cookie和新旧更新文件名筛选。

原C算法的宿主基线另复跑210检查及排序484pairs。没有把七字节GIF、Unicode密码的已知异常放进 Android 普通通过用例：它们在隔离宿主子进程继续复现，仍是 P5/P6 待修复问题。

最终抽屉/资源清理后重跑的输出单独标为 final-device-*.log；保留首次执行证据，避免覆盖测试历史。APK静态验证覆盖全部64位库的16KB LOAD与压缩包对齐；设备动态测试仅ARM64，ARM32/x86_64运行时尚未在本机验证。

Baseline Profile执行日志另存；即使生成成功，也不把联网gallery journey的超时/缺失节点当成完整核心功能或性能验收。
