- `app/src/main/cpp/CMakeLists.txt`：最低 API26 后固定选择原有 android-26 feature，删除低版本选择分支，不改 Rust 实现。

- `coil/CropBorderInterceptor.kt`、`coil/HardwareBitmapInterceptor.kt`、`util/LauncherUtils.kt`：移除失效的 RequiresApi26 注解与对应 unused import。

## 风险与回滚

min26 排除了 Android6/7（API23–25），不只是 Marshmallow。旧 `.m` 应用使用独立包名，不能直接覆盖成默认包，应先导出/备份，再另行迁移。未执行卸载或跨包私有数据复制。

资源移动保持 API26及以上解析值；传统 bitmap fallback 图标仍保留，不做目录大重组。更高 API 的存储/通知/DNS条件分支仍保留。

Release 工作流为单 Flavor 同步到四 APK + mapping/symbols 六附件；最终“四且仅四 APK/受控符号存储”的发布策略属于 P9，未在本阶段完成或执行发布。完整回滚补丁见 README；回滚应同步恢复 app/benchmark、helper、更新器、资源与任务路径，不能只恢复一个 Flavor 定义。

最终验收：标准构建重试成功（2m10s）；移动资源后的初次增量链接缺少shortcuts，强制merge资源成功后重试通过。清理本地空限定目录并刷新Lint成功（54s），实际47项warning、0 error；保留2项IconXmlAndPng和1项ChromeOsAbiSupport，未禁用检查。诊断init脚本首次作用到included build失败，限定main build后通过，原始失败日志保留。
