# Shared reader page jump

The existing counter opens one localized common CMP Go to page dialog in the paged and continuous readers. It accepts ASCII one-based page numbers with range/overflow checks, selects the initial number for replacement and keeps cancellation available during loading. Invalid input never clamps to another page or requests metadata. Android phone/tablet, Desktop and iOS use the same implementation and four resource catalogs.

Paged navigation uses the existing readingResumeUrl and decoded preview tokens, including bounded preview-window resolution. It never invents service tokens. Cancellation is checked before navigation; a metadata failure preserves the current page, saved progress and entered value for explicit retry. Selecting the current paged position avoids another request. Only successfully decoded images can save progress.

Continuous mode freezes source-window focus and progress writes while the dialog or its final positioning is pending. Dismissal restores either the chosen page or the original index/offset after the keyboard closes, using a next-measure request and a viewport/item-size bounded offset. This prevents keyboard backfill from becoming a reading action.
