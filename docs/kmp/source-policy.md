# Auditable source boundary

`verification source-policy` audits the target repository against the fixed M0 commit `423b8af13632896b55780783b54b5f720ec4c9dd`. Full history and baseline ancestry are required; an absent/shallow/unrelated baseline fails rather than producing an empty audit. It checks cumulative tracked changes, index/worktree changes and nonignored untracked files, with NUL-delimited Git paths. Existing unchanged historical tools remain in place. Changing them requires an independently reviewed policy exception or a Kotlin/Rust replacement; this change introduces no exception.

Both working bytes and the actual staged Git blobs are inspected. Restoring or deleting the working copy after staging cannot hide a forbidden implementation or reference header; unmerged indexes fail. This check never resets, stages, commits or changes repository content.

Changed implementation with Swift, Objective-C, Java, C/C++, Python, JS/TS, Shell or other listed language extensions is rejected, including case variations, renamed files and non-Gradle `.kts` scripts. Interpreter shebangs cannot be hidden in resource filenames. New maintained source uses `.kt`, `.gradle.kts` or `.rs`. Necessary declarative configuration, resources and compiler/third-party output remain distinct from owned implementation. Ignored build output is not maintained source; force-adding it makes it part of the audited index. This does not claim that arbitrary code disguised inside every possible resource/configuration format is detectable.

All indexed symlinks/gitlinks and untracked nested repositories are rejected. Every inventoried path is checked for symlink ancestors before any changed file is read. This prevents a reference directory from becoming a source input through a symlink, submodule or untracked embedded checkout. The real CLI checks the EhViewer origin and never opens, builds, hashes or writes a local Animeko checkout. It works on a hosted runner with no reference directory.

Recognizable reference package/import prefixes and AGPL SPDX headers in changed Kotlin/Rust trigger separate provenance/license review; diagnostics print paths, not source contents. These heuristics cannot establish the absence of copied or mechanically rewritten code. Human reference review, independently designed contracts, recorded differences and approval before any exact reference reuse remain mandatory. `complete_copy_or_license_audit` deliberately remains `NOT_VERIFIED`.

The three retained Skiko license/notice/origin files are checked against independently audited SHA-256 values, preserving their upstream Apache-2.0 identity and exact bytes. See `app/desktop/licenses/skiko-0.144.6/origin.toml` and ADR0004. Their origin is JetBrains Skiko, not Animeko. Required audit documents must exist. This is a bounded check of directly retained material, not a complete dependency SBOM, final resource provenance audit or proof of license compatibility. New vendored material and the unified platform icons require their own source/license records and validation before acceptance; no blanket vendor exemption is added here. Existing M0 wrappers, CMake/third-party patches and generated fixtures retain their original audit status.

`ci/source-policy` builds/tests the verifier, runs the real audit without production keys and retains source-bound JSON. `ci/gate` always runs and requires its actual success in addition to every previously mandatory job. The existing Android architecture/language check and all original Android/Native/publication regressions remain mandatory. No production Release path, secret, dependency, application version, platform runner or test timeout is changed.

Tests use owned temporary Git repositories to exercise new/staged/committed/renamed forbidden source, edits versus unchanged historical tools, untracked Unicode paths (including newline paths on filesystems that support them), ignored generated output, shebang disguises, reference markers, symlinks, gitlinks, embedded repositories and invalid/missing/unrelated baselines. The aggregate gate is executed with each source-policy failure/cancelled/skipped/neutral/pending/empty result and must reject it. Actual hosted results remain required for the new commit.
