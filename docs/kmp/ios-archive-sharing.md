# iOS archive sharing from the common library

The same CMP local-library screen exposes Share comic only when a platform supplies an actual activity adapter. iOS presents UIKit's system share sheet using an immutable export snapshot; Desktop retains its real file/folder export and Android retains its existing platform routes. No placeholder share operation is installed on an unsupported platform. The common UI distinguishes completion, dismissal, coroutine cancellation and failure without claiming recipient delivery.

`AppleArchiveShare` uses Kotlin/Native and `UIActivityViewController`, with an explicit live-window popover anchor on iPad and native modal presentation on iPhone. Its request retains the weak presentation delegate. UIKit completion reports the activity result; interactive dismissal is cancellation. Coroutine cancellation and composition disposal dismiss the sheet on Main and await dismissal before releasing the snapshot. Compressed/encrypted bytes and ordered folders reuse the previously tested export implementation; the original private book is never given to an external app. A completed activity establishes system handoff, not remote delivery.
