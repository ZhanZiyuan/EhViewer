# Explicit original images in the shared reader

The paged CMP reader can load the original image advertised by its actual page document and return to the display image. The choice belongs to the current page; navigation resets it. Reading position still records the gallery page identity, not the original image URL. Local archives and cached pages do not advertise a remote original action. Continuous-reader quality preferences and original-image bulk downloads remain later work.

`GalleryContent.originalImage` is implemented by the existing Ktor repository. It validates the selected gallery page and the same service's HTTPS `/fullimg/{gid}/{token}` entry before making any request, then uses the existing bounded image transport, page referrer, cookie isolation and validated redirect chain. Errors, HTML, login redirects, oversized responses and cancellation do not silently substitute a display image. The UI retains an explicit return-to-display action. An invalid unused optional original link does not break default image reading.

The implementation reuses EhViewer's own `EhEngine.getOriginalImageUrl`, `SpiderQueen` protocol behavior, original Rust gallery-page parser and existing shared reader design. No new Animeko implementation is used or copied; the existing shared/platform architecture reference and license boundary remain documented in `animeko-reference-audit.md`. No dependency, Rust ABI, database schema, signing rule or application version changes.

Eight common Ktor regressions cover both services, real redirect execution, referrers, credential isolation, malformed/foreign/gallery-mismatched entries, default-display compatibility, forbidden destinations, authentication, server/challenge/rate-limit errors, HTML/size limits, redirect loops and cancellation. The complete network suite now requires 108 executed tests, retaining every previous suite. Existing Android integration uses actual Rust page parsing, actual Ktor responses and the real CMP image decoder. It requests the original through its redirect and checks actual screen pixels against a distinct owned PNG, then restores display pixels and preserves the same Room reading position.
