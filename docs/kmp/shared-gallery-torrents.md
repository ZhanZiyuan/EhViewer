# Shared gallery torrents

The common detail page restores `Torrent (count)`, the original centered title, compact two-line rows, outdated date color, counters and marquee. Selecting a row hands a validated magnet to the platform. A missing handler copies it, as on Android 1.15.10. Only a failed clipboard fallback adds an explicit retry. Back/outside dismissal and Desktop Escape cancel the actual pending request. Desktop/tablet dialogs cap their width at 640dp; phones retain the original row geometry.

The existing Rust torrent parser remains the source of the fields. The additive JNI/C ABI adapter rejects missing/partial documents, invalid UTF-8 and nested-table amplification before legacy captures. The existing bounded Ktor/session transport requests `gallerytorrents.php` with the original gallery referer, never treating authentication, challenge, rate or server errors as an empty list. Only validated HTTPS service/tracker links and hashes may reach the magnet handler; duplicate, oversized and malformed results fail explicitly. The zero-count action needs no network request.
