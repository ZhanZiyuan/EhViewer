# Recoverable local-library inspection

A malformed `book.cbor` previously failed the whole local-library listing, hiding unrelated healthy books. The common `ArchiveLibrary.inspect()` now returns validated header entries and an explicit unreadable-copy count. The same CMP screen on Desktop and iOS shows the count, explains that files are retained, offers retry and keeps healthy books available. `recent()` retains its strict contract for existing consumers. Root listing failures and cancellation still fail; they cannot masquerade as an empty successful library. Inspection verifies private headers/layout metadata, not every image hash; normal open/read retain their content verification.

No corrupted or unknown bytes are rewritten, moved or deleted. Restoring a damaged header makes the book visible on retry. Unknown staging directories are retained: automatically deleting them without cross-process ownership would risk another active import. Abrupt-kill staging reclamation remains outstanding. There is no destructive recovery action or database-format change in this slice.

Library shutdown also attempts every owner when one close throws, waits for all remaining admitted calls to finish and reports a sanitized storage failure afterwards. A caller's cancellation cannot skip this cleanup. A failed owner remains explicitly failed and is not reported as released. The previous closed-document reference clearing remains intact. This repairs exception/cancellation behavior without changing Rust ABI or treating an unresolved native close as success.

Four real-file recovery tests cover malformed/missing headers, preserved interrupted input, restoring metadata, single-copy I/O failure, whole-root failure and cancellation. Two additional ownership tests cover failure propagation across multiple documents and cancellation before shutdown. Existing lease/concurrent-read and all directory tests remain mandatory. Packaged Desktop/iOS regressions additionally inject malformed owned metadata, keep both valid books readable through actual Rust/platform decoders, verify unchanged corrupt bytes and remove only their explicit fixture. Android adds the equivalent real JNI/pixel regression.

Reference: the previously audited read-only Animeko `docs/contributing/architecture.md` storage/platform boundary is adopted; EhViewer's private archive metadata, failure reporting and Rust owner behavior are independently implemented in `ArchiveLibrary.kt`, `FileArchiveLibrary.kt` and `ArchiveLibraryScreen.kt`. No Animeko source, script, asset or dependency is copied. No new implementation language or dependency is added.
