Status: GATE_PASSED at 28ab24263afb924edc6cfbb9d217b8ea3b0ba69c. M2 remains incomplete; stable version 1.15.10 / Android 180074 is unchanged.

Combining baseline-to-worktree changes with nonignored untracked paths covers earlier commits, staged changes and local omissions without relying on the private Animeko directory.
