# ADR 0022: Verify official artifact transport before staged aggregation

Status: IMPLEMENTED / LOCAL_VERIFIED / CI_PENDING. This is an intake component; staged product package aggregation remains pending.

After accepted50d1, actual Windows ZIP extraction/native startup and every existing platform proof are available. A later required packaging aggregator must first consume genuine same-run artifacts without trusting names, mutating inputs or overwriting user data. Keep the intake boundary independently reviewable before adding cross-platform package policy.

Add a portable Kotlin byte inspector to the existing verifier. Require a complete official catalog, unique IDs/names, exact run/head, nonexpired metadata and matching official archive size/SHA. Validate every ZIP path/entry/bound before creating a fresh canonical output root. Extract only ordinary bytes, check streamed CRC and read every file back, preserve the input archive and reject existing outputs/aliases. Unix link attributes cannot create links. Retain explicit transport-only receipts; executable permissions and product/native acceptance are not provided by this inspector. PR run-head and test-merge provenance remain distinct.

This component performs no network access, publication, signing or production-workflow changes. The caller remains responsible for authenticated metadata/archive retrieval. Existing source/phase/shared/Android/Native/desktop/iOS and publication state-machine checks remain intact. The next independent aggregation change must still validate real installation packages, source/version/architecture, hashes and successful native receipts. A transport receipt cannot satisfy that package gate.

Design references are EhViewer's accepted WindowsStageZip/WindowsZipLaunch safety boundaries, actual official artifact metadata and the user's PRD. No new Animeko code, assets, scripts, dependencies or architecture reuse occurs. Maintained implementation is Kotlin only. Validate complete local tools/Android/preflights, the exact inspector on previously accepted real transport archives, and both new-SHA hosted workflows/all applicable actual artifacts before acceptance.
