# Shared History screen

The shared History page now follows Android 1.15.10's `HistoryScreen` on every platform. It uses the same floating Material 3 search bar as the search page. On phones the bar leads with the drawer button, beside the rail with a search icon, and its placeholder shows "History" until focused, then "Search History", using Android's own `history`/`search_bar_hint` translations. Its trailing action is Android's Clear all, which asks "Clear all history?" first. Entries are Android list cards (the same cards as search, including the downloaded mark) in one column with `gallery_list_margin_h` margins and 12dp spacing, scrolling beneath the bar, which slides away with them. Swiping a card toward the start forgets the entry, as Android's `SwipeToDismissBox` does; the card also offers Remove from history as an accessibility action. An empty history shows Android's 120dp History icon in the primary color over its headline "Viewed galleries will be shown here"; a search with no matches shows the no-galleries text instead. Loading covers the list with a centered indicator, and a load failure shows the shared ErrorTip, which retries when tapped. History now joins search as a full-width page; the "Back to search" button and the plain list rows are gone, and Back still returns to search.

The search filters the loaded entries (the 100 most recent) by English or Japanese title as the user types. Android instead queries its database when the search is submitted; that difference is recorded.

`GalleryHistoryStore` gains `clear()`. `RoomGalleryHistoryStore`, the only implementation, behind Android, Desktop and iOS, deletes every history row but, like `forget`, keeps gallery metadata and reading positions. A new store test covers this and that reopening a cleared gallery restores its entry. `GallerySearchBar` now takes the page title, hint and trailing actions, so both pages share it.

Targets: GalleryHistoryScreen.kt, GallerySearchBar.kt, GallerySearchScreen.kt, GallerySearchCard.kt (modifier), GalleryIcons.kt (ClearAll), the four catalogs, GalleryHistoryStore.kt, RoomGalleryHistoryStore.kt, RoomGalleryHistoryStoreTest.kt, GallerySearchBarTest.kt and GalleryPreviewIntegrationTest. The real Android flow now finds History by its search field, swipes the card away and requires both the store removal (with the reading position kept) and the card's disappearance, then leaves through navigation.

Local results: Android spotless/unit/host/lint/assemble, core data Desktop and Android host tests (including the new store test), shared Desktop tests, the Desktop app compile and the iOS arm64/simulator compile and debug link passed. The phone and tablet each passed 50/50 serially with the same APK pair and zero skips. The native core:data test needs CI's test directory property and runs in CI. No Desktop window or iPad interaction has been recorded for this change yet.

Animeko was not consulted for this change; no AGPL code, assets or scripts are used. M5/M7/M8 stay open; stable 1.15.10/180074 and Draft PR15 remain.
