# Native macOS ARM64 DMG

The existing Compose Desktop distribution now produces a real ARM64 DMG on Apple ARM hardware. The verifier mounts it read-only, installs an owned temporary copy, checks the complete native/JAR inventories and dependencies, then launches the installed application twice using its bundled jlink runtime. Each launch executes the existing gallery5/account4/history3/archive9/language4 regressions, native browser ownership and Rust100 calls and renders a real Compose window. The installed Rust library also passes the original JNI4170 and thirteen immutable archive cases through the external test JDK; that separate invocation is explicitly distinguished from bundled-runtime execution.

The first package check exposed two existing distribution problems. The ARM Skiko archive included an unused Intel dylib, and the Rust library inherited a Homebrew libarchive dependency. The target-only selector now independently pins the original ARM and Intel upstream JAR hashes and removes only the opposite Apple CPU. It does not mutate Gradle's upstream cache. The native Rust task explicitly selects the Apple SDK's system archive ABI ahead of inherited library paths; WebP still builds from the unchanged pinned source. The real installed dependency scan rejects build-machine paths. The pinned WebP source and bundled JDK/Skiko versions stay unchanged; production signing settings are preserved.

The existing `--m1-smoke` packaged regression accepts native macOS ARM64 as well as its retained Intel/Linux ARM/Windows ARM targets. Normal launches still enter the same shared CMP application. This reuses EhViewer's own product tests and Rust integration. No new Animeko implementation, scripts, assets or dependencies are reused; the architecture/reference decisions remain in [the original audit](animeko-reference-audit.md).

The existing macOS ARM `rust_host` job retains all original JNI, Keychain and common-JVM checks and additionally builds, installs and tests the DMG. Its existing source-bound artifact contains the exact tested DMG and all reports. No new artifact download, runner, workflow or artifact catalog role is introduced. The strict staged dry-run checks clean matching source/version/native execution, two real launches, native-browser ownership, JNI/archive evidence and actual UDIF bytes before retaining the eighth candidate as `EhViewer-1.15.10-macos-arm64.dmg`. It computes the source hash once and checks the retained copy. The Intel ARM/Rosetta producer and physical Intel consumer remain required independently.

Gradle and Rust caching can now retain results only for this repository's `feature/kmp` PR #15, in addition to each action's existing main policy. Other PRs retain the original read-only behavior and workflow `contents`/`actions` permissions remain read-only. [GitHub's documented PR cache isolation](https://docs.github.com/en/actions/reference/workflows-and-actions/dependency-caching#restrictions-for-accessing-a-cache) prevents main from restoring these PR-only caches. This avoids repeatedly discarding this migration's tool downloads and reusable compilation outputs; speed improvement is not claimed until measured. All required jobs, Android regressions, test commands, source/output binding and the Full release dry-run stay mandatory. The verifier checks are rerun after the YAML change.
