# Common Coil cover loading

PRD8.3 requires cross-platform Coil3. Previously the common result cards downloaded/decoded directly while Coil was confined to Android. The same CMP cards now execute through a session-owned Coil3.5.0 loader on Android, Desktop and iOS. The existing version stays pinned; Kotlin/Compose/Ktor/Skiko versions and Android's application singleton remain unchanged. This slice covers static result images; the existing full reader/GIF/Rust-WebP capabilities retain their own tested pipeline during incremental migration.

Targets are `app/shared` common `GalleryCoverLoader.kt`, `GallerySearchScreen.kt`, `GallerySearchCard.kt`, `GalleryImage.kt`, and the existing Android/Skia actual decoders. Only the shared dependency/catalog alias is extended. A typed fetcher delegates to the existing gallery repository: actual Ktor client/cookies, strict host mapping, gallery Referer and bounded transport. URLs never reach another HTTP client. Service-loaded components are disabled. A private source type selects the original bounded first-frame decoder; the sampled flag reflects original dimensions. Platform bridges share the resulting Bitmap with Coil's common Painter, retaining temporary-owner cleanup.

The page-owned16 MiB LRU and single download/decode admission remain authoritative. Additional Coil memory/disk caches are disabled. Covers remain at most512px per edge/1 MiB RGBA; encoded input keeps the repository's32 MiB maximum. Coil closes the fetched source after decode. Failures stay sanitized and explicit retry remains required. Buffering is bounded, but no peak-memory/performance improvement is claimed. Caller cancellation remains structured. A session Job additionally cancels active execute requests and rejects work after closure; completed page pixels stay readable and completion registrations are disposed.
