# Shared baseline typography

The shared Material 3 theme uses Roboto Classic 3.005 with explicit weight, width and italic axes. Standard and emphasized roles retain their existing sizes, spacing and line heights. Android's production destination continues to supply its original `EhTheme`; the common typography supplies the other platforms and standalone shared hosts.

The Android API 36 reference's actual `TextRunShaper` output identifies `/system/fonts/Roboto-Regular.ttf`. Its SHA-256 is `9ca9debb09459bf4e3e7f826f5cd0f35f253902b85684921fce2ba3f28dd0f50`, identical to the unmodified resource from [AOSP revision 5d982bb](https://android.googlesource.com/platform/external/roboto-fonts/+/5d982bb4526f3e8a438a776619c060e1daf2f18f/README.android). The Apache-2.0 notice, attribution and pinned origin are packaged in `composeResources/files/licenses/roboto/`. No Animeko asset or implementation is used. APK and Simulator resource inspection verifies the font bytes.

Settings and detail layout regressions render the actual product theme at narrow/wide widths and large font scales. The final frozen APK pair passes all 52 tests on each Android phone/tablet, with no skips. Android formatting/build/lint/unit checks, all 113 shared Desktop tests and macOS packaging pass. The already executed Native 79-test pass and both iOS application compiles are retained: all bound font/shared-source hashes are identical, and the only intervening committed changes affect the Windows verifier. This source-equivalence audit is not a new test run. Each new SHA still needs its applicable hosted gate.
