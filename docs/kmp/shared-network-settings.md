# Shared network request timeout

The common CMP settings page offers the platform default or 10/30/60/120 seconds on Android, Desktop and iOS. The actual application factories supply one independent nonsecret DataStore record. All Android client/UI adapters reuse the same application-lifetime store; they do not independently open the same file. The default keeps the existing Android 10-second and common-client 30-second request limits; selecting a value affects subsequent requests. A request with its own explicit limit retains it. Existing connection/socket limits, transport engines, TLS, DNS, redirects, cookies and credentials remain authoritative. In-flight requests are not restarted or retried.

A common Ktor plugin reads the current DataStore snapshot before sending. The same preference reaches the real search/content/favorite/download client and newly created authentication/account clients. Android installs it on its original application client and uses the same saved preference from the shared screen. No replacement cookie store or duplicate production engine is introduced. Unreadable preferences surface the existing recoverable local-storage error before sending. The UI disables failed updates until the persisted value has been reloaded; persistence failures are not presented as saved choices.

The versioned record validates all saved/new values, preserves unrelated keys and rejects corrupt/future files without overwriting their bytes, including reset. Cancellation propagates. The implementation follows the previously audited shared-settings/platform-ownership boundary in Animeko `docs/contributing/architecture.md:112–153`, adapted to EhViewer's own client and DataStore. Target files are `core/domain/.../GalleryNetworkPreferences.kt`, `core/data/.../DataStoreNetworkPreferences.kt`, `core/network/.../GalleryNetworkTimeout.kt` and `app/shared/.../GalleryNetworkSettings.kt`. No reference code, scripts, resources or dependencies were copied. The [Ktor timeout API](https://ktor.io/docs/client-timeout.html) and [request hook](https://api.ktor.io/3.5.x/ktor-client-core/io.ktor.client.plugins.api/-client-plugin-builder/on-request.html) describe the public APIs used.
