# Shared gallery tags and scoped navigation

This M5 slice replaces plain detail tag text with the same common Material3 wrapping pills on Android, Desktop and iOS. Namespace pills use primaryContainer, tags use tertiaryContainer, with the original64dp shape,4dp outer spacing,12/4dp text padding and weak-tag opacity. A weighted flow bounds long tags on phones and wide windows. Clicking a tag performs a real scoped request.

The reference is EhViewer `v1.15.10`, commit `423b8af13632896b55780783b54b5f720ec4c9dd`: `app/src/main/kotlin/com/hippo/ehviewer/ui/main/GalleryTag.kt` and `client/data/ListUrlBuilder.kt`. Targets are common `GalleryDetailTags.kt`, detail/search routing and `GalleryRepository.kt`. This stays within the existing project's license; no Animeko implementation, assets, scripts or dependencies were copied. Android-specific translation/context-menu/vote settings remain further work. No inactive menu actions were added, and full pixel parity is not claimed.

The network uses Android's `/tag/{namespace:text}` route. Literal Unicode, spaces, slashes, quotes, `?` and `#` remain one encoded segment rather than search operators. Invalid namespaces, empty/control/oversized names and malformed request/response cursors fail explicitly. Retry, paging and resubmission preserve the committed tag route; editing the query returns to normal search. Server failure and cancellation do not produce fabricated empty success.
