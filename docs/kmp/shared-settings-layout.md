# Shared settings layout

The common CMP screen restores the v1.15.10 root order: EH, Download, Privacy, Advanced and About. Rows use the original primary-color 24dp icons, 56dp minimum height, 16dp padding and `titleMedium`. The title/back app bar reaches the content viewport's edges and exposes a real 48dp Back target. Localized preference labels wrap beside their controls. Host safe-drawing insets apply once; wide windows retain the shared 1040dp content cap and adaptive navigation.

Reference: EhViewer v1.15.10, `423b8af13632896b55780783b54b5f720ec4c9dd`, Android `ui/settings/SettingsScreen.kt`, `PreferenceWidgets.kt`, `ui/Theme.kt` and existing `core/ui/icons/filled/SadPanda.kt`. The pinned Preference 2.2.0 artifact was inspected for geometry without copying its implementation. Targets are common `GallerySettingsOverview.kt`, `GallerySettingsScreen.kt`, `GallerySearchScreen.kt` and existing theme adapters. Material icon paths retain Apache-2.0 provenance; SadPanda is the existing EhViewer asset. No Animeko code, resource or dependency is copied; its checkout remains read-only.

EH retains gallery/reader controls, Download retains real storage controls, and Advanced retains language, appearance and network settings. Privacy routes to existing Account and History management; About opens the actual repository and license. These destinations do not implement every original privacy/security or updater option. Saved category selection survives recreation. Back returns to the root before leaving Settings. Android retains its original Dynamic Color adapter; other platforms retain the common Material3 palette contract.
