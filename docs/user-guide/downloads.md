# Downloads and custom order

## Save and manage downloads

1. Open the gallery details and choose **Download**.
2. Open **Downloads** from the navigation menu. Use the action on a row to start, pause, or retry the task. The overflow menu also offers **Start all** and **Stop all**.
3. Tap a completed gallery to read it. Long-press a gallery to select it for actions such as moving it to another label or removing it. The removal dialog offers **Delete image files** when you also want to remove the files.

Use **Download options → Download labels** to navigate collections and manage label order. Changing a label's position changes the order of the labels. The gallery order is set separately.

## Choose a folder or CBZ format

Open **Settings → Download → Download location** and select a folder through the Android picker. If access stops working, select the folder again and grant access. **Save as CBZ archive** combines completed pages into one archive. **Preparing CBZ** indicates that the archive is being made. **CBZ failed** indicates that the archive step needs attention. The app checks the saved archive before cleaning up source images.

## Set a custom order

**Custom order** is available starting with v1.15.15.

1. Open **Downloads** and switch to the list using the list or grid button at the top.
2. Tap **+**, open **Sort by**, select **Custom order**, and clear **Group by download label**.
3. Show **All** downloads or select one download label. Close search, clear its text, set the status filter to **All**, and exit any selection.
4. Drag a gallery by the handle beside its task action. With a screen reader, use **Move up** or **Move down** on the handle when offered.

The order is saved when you finish a move. It carries over when you return from grid view or switch back from an automatic sort. The grid displays the custom order and editing takes place in the list. Searching, filtering by status or artist, or grouping by label can hide the handle so a filtered subset does not accidentally change the library's order.

Automatic sort choices cover added time, uploaded time, title, and page count in both directions. They use the standard download card layout. The custom drag handle sits next to the task action, with the page count aligned to the same edge as in the automatic views.
