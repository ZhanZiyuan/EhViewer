# Browse, read, and organize galleries

## Browse and search

- Open **Homepage** to search by keyword and category. Use the advanced search options for narrower queries.
- Use **Subscription**, **What's hot**, and **Toplist** to browse those gallery feeds where the selected site offers them. Manage subscribed tags through **Settings → EH → My tags** when signed in.
- Open **Quick search** and tap **+** to save the current gallery search. Run the search first so the saved shortcut includes its search options.
- Open a gallery's details to inspect its title, tags, previews, and available actions. **Settings → EH** controls gallery list display, title language preference, tags, comments, and blockers.
- To open supported gallery links directly from other apps, enable **Open supported links** in EhViewer's Android app settings. Android 12 and later may ask you to select supported sites there.

## Read a gallery

Choose **Read** on the details page or select a page preview. Tap the center of the reader to show its controls, jump to a page, or open reader settings. Choose a left-to-right, right-to-left, vertical, or Webtoon reading mode for the gallery. The reader settings can also enable volume-key page turns. To show saved reading progress in gallery lists, enable **Settings → EH → Show reading progress**.

## Favorites and history

Use the favorite action on a gallery to save it to **Local Favorites** or an available account collection. Open **Favourite** from the navigation menu to browse saved galleries. Sign in to access remote favorites. **History** lists previously opened galleries and lets you reopen them.

## Save galleries for offline use

Choose **Download** on a gallery, then open **Downloads** for progress and completed items. A saved gallery can be opened from that list. In **Settings → Download**, set the download folder and decide whether completed downloads should be saved as CBZ archives. **Download labels** organize saved galleries separately from the website's tags.

## Export and import app data

Open **Settings → Advanced → Export data** and save the export somewhere you can access later. **Import data** reads a previously exported file. The export contains app records such as download entries and quick searches. Copy the actual downloaded image folders or CBZ files separately when moving to another device. After granting access to the download folder on the new device, **Settings → Download → Restore download items** can rebuild entries from files already present there.
